# 2026-11-18 測試資產

用途：T1／T2／T3 三組 H3 實測的參考圖。全部用本機 ComfyUI 的 Qwen-Image 2.1 turbo 生成
（6 步、euler、simple、`qwen_image_2.1_turbo_int8_convrot`），不是外部圖庫。

| 檔 | 角色 | 種子 | 解析度 | 備註 |
|---|---|---|---|---|
| `hero-front.png` | 女劍客，正面站姿 | 11 | 832×1216 | T1／T2 的參考圖；T3 的「正面」對照組 |
| `hero-side.png` | 女劍客，側面朝右、低架、雙手持刀 | 31 | 1216×832 | T3 的「側身戰鬥」組（與 T1 只差這張圖） |
| `villain.png` | 蒙面力士，背面轉頭、持鐵棍 | 22 | 832×1216 | 手部融合明顯，可當身份參考、不可當解剖參考 |
| `scene.png` | 雨夜廢寺庭院，無人 | 23 | 1216×688 | 冷暖雙光、前中遠景齊 |
| `hero-34-failed.png` | 失敗的「三分之四側身」嘗試 | 21 | 832×1216 | 留著當反例：模型把「背向鏡頭」畫成背對，手部握持也不清 |

生成提示詞在同目錄 `prompt-*.txt`。負面约束固定在提示詞句尾（`no text, no panels...`），
沒有另外掛 negative prompt（Qwen 這條 turbo 走 BasicGuider）。

**已知限制**：所有圖的手部都有不同程度簡化（AI 生圖通病）；H3 會重繪，所以可接受，
但若要當解剖或武器結構參考，需另外重畫。
