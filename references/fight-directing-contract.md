# 高密度打鬥導演合約（Fight Directing Contract）

> **核心原則**：先導演戰鬥，再寫提示詞；絕不以堆疊招式、特效或運鏡詞代替連續攻防。
> 本合約融合「上游導演漏斗（事實帳本 → 戰鬥載體路由 → 三層編排 → 狀態接力）」與「雙語同步編譯（中文母稿 → H3 Ref2VA 英文六段）」。

---

## 0. 時長路由（先於段落格式）

先依指定時長選擇結構，再開始動作編排：

| 指定時長 | 結構 | 節奏與收尾規則 |
|---|---|---|
| **約 15 秒（或未指定）** | **五段狀態接力**（中文七段母稿） | 0–3s 即時搶攻 → 3–6s 變軸首中 → 6–10s 技術逆轉 → 10–13s 封鎖折返 → 13–15s 三拍終結與明確結果 |
| **10 秒及以內** | **四段短時長結構** | ① 即時搶攻 → ② 接觸後變線 → ③ 持續追擊與攻守轉換 → ④ 進行中的切出或指定結果。**嚴禁把 15 秒五段終局硬壓進短片。** 未指定勝負時，最後一幀仍在攻擊、閃避、追擊、滑行或環境連鎖中 |
| **多段拼接（>15 秒）** | 先交三表（節拍表／狀態帳本／接縫表）再逐段寫 | 詳見 `references/segment-continuity.md` |

### 疊加開關：無停頓連續模式（No-Pause Overlay）
當使用者要求「無蓄力」「無停頓」「不停」「全程連打」或 `ULTRA_SPEED` 時，在任一時長結構上疊加：
- 快慢節奏**只能**透過攻擊頻率、動作幅度、位移距離、切鏡密度、鏡頭速度與接觸密度呈現。
- **嚴禁**寫成角色停住、速度歸零、收勢、站定、凝視、蓄力、制動、擺姿或靜態展示。
- 每個區間／鏡頭末尾**必須已經觸發下一動作**；角色、武器、衣料、碎屑、環境物或攝影機至少一項持續運動。
- 關鍵接觸的「短促清晰」只指攝影機對接觸點的可讀性，不是角色或動作停頓。

## 1. 事實優先級與資產零推斷

### 1.1 五級事實優先級（衝突時嚴格按序裁決）
1. 使用者明確指定的角色、裝備、能力、動作、勝負、時間點與禁止項；
2. 參考圖清楚可見的外觀、服裝、持有物、身體結構、能力介質與能量效果；
3. 已確認身分且與當前版本相符的戰鬥習慣；
4. 維持動作連續性所需的最小補全；
5. 導演原創。

身分不明時使用穩定外觀稱呼；不從面部猜測現實身分，不從職業稱號自動補武器、門派、招式或能力。

### 1.2 參考圖職責分配
逐張為每張參考圖指定唯一職責：
- **動作起點圖**：鎖定身分、裝備、朝向、接觸關係、支撐面與空間關係；動作與鏡頭可立即改變景別與取景，**不強迫復刻原構圖**。
- **角色圖**：鎖臉型、眼、疤、髮型、配件數量、服裝結構、配色、剪影比例與可見武器（搭配 `references/ref-identity-lock.md` 9 類特徵清單）；不繼承原圖站姿與背景。
- **場景圖**：鎖建築、材質、光源、天氣、地形、通道與高低差（只當環境基礎，不鎖死原始機位）。
- **設定圖／三視圖／四視圖／海報拼貼**：同一角色重複出現不增加人數；文字、標籤、水印、邊框與裝飾均非戰鬥物體。

### 1.3 武器與能力零推斷帳本
為雙方（A / B）分別建立獨立帳本：外觀錨點、身體結構、服裝、戰鬥目標、武器（種類／數量／材質／相對尺寸／持握）、能力來源、能量規則、移動條件、開場位置、禁止補全項。
- **零推斷**：圖中沒有且使用者未指定的武器或超自然能力，**不得新增**；無武器角色全程徒手。
- **防串線**：雙方裝備、武器、服裝與能量色嚴禁互相污染；武器不得無因變形、消失、複製或換手。
- **單人圖補對手規則**：若要求「打鬥」但參考圖僅清楚呈現一名主體，允許補一名**最小化輪廓對手**（無獨立臉部、服裝細節、武器或超能力，預設徒手），並在中英文稿中同步標明為導演補全。
- **無能力角色表現力**：以體態重心、衣料慣性、空氣壓縮、塵土碎石、摩擦與材質破壞呈現速度與重量。有能力者必須寫清來源、方向、接觸對象與殘留，不憑空爆炸、不遮擋攻防主體。

## 2. 戰鬥載體自動路由與非對稱攻防矩陣

依每個主體真實可見或指定的資產，選擇唯一主載體（最多組合已具備的兩種，例：「徒手＋已確認雷電強化」），**禁止把不同載體寫成同一套劍法或徒手招式**。

| 載體 | 專屬動作語彙 | 必要物理回饋 |
|---|---|---|
| **刃器**（刀／劍／雙匕） | 斬、刺、挑、格、撥、壓、繞、滑刃、貫穿；攻擊線沿刃口與劍尖展開 | 切割軌跡、火花、裂口、斷面、刀劍偏轉、逼離中線 |
| **長柄武器**（槍／戟／棍） | 中線壓迫、遠距刺擊、壓桿、挑擊、橫掃、槍尾短打、折線追刺、回馬擊 | 距離優勢、桿身轉向慣性、回收時間、被貼身後的不利 |
| **鈍器**（錘／斧／棒） | 砸、壓、推、撞、掄、震擊 | 凹陷、塌陷、碎裂、低頻衝擊、大幅擊退；禁寫成輕飄劍法 |
| **遠程武器**（弓／槍械／暗器） | 瞄準、發射、追蹤、規避、攔截、換位 | 彈道／射線方向、遮擋關係、發射間隔、掩體破壞 |
| **徒手** | 拳、掌、肘、膝、腿、肩撞、擒拿、卸力、翻摔、貼身閃避、踏牆借力 | 雙手空置；對鋒刃靠切線、控非鋒利部位、貼身或環境反制 |
| **能力型** | 牽引、壓縮、塑形、包裹、偏轉、束縛、局部強化、環境操控 | 必寫來源部位／武器、方向、接觸對象與殘留；禁無源光球對轟 |
| **飛行生物** | 振翼、收翼、俯衝、翻滾、爪擊、空中制動 | 翅膀結構、升力氣流與轉彎半徑可信 |
| **四足／多足／巨獸** | 蹬地、撲擊、攀附、撕咬、甩尾、踐踏、重心壓砸 | 足數、關節方向、抓地力、慣性與尺度參照（見 `monster-scale.md`） |
| **機械／載具** | 依可見推進器、輪組、機械臂、砲口、裝甲啟動、加速、規避、撞擊、制動 | 不新增圖中不存在的功能；回饋來自真實傳動、裝甲與推進結構 |

### 六種非對稱攻防校驗
1. **雙方持械**：依長度、重量、攻擊方向差異設計壓制、滑開、纏繞、拆線與反震。
2. **持械對徒手**：徒手方採側閃、貼身切入、踢腕、控臂、抓握非鋒利部位、肩撞、翻摔或環境借力；**除非明確設定，嚴禁裸手硬接鋒刃**。
3. **持械對能力**：能力方以有明確來源的局部防禦、牽引、偏轉或束縛處理攻擊，寫清武器接觸點與受力結果。
4. **雙方徒手**：只用拳腳、擒拿、摔投、衝撞與地形借力；禁刀光劍鳴或金屬碰撞。
5. **雙方能力**：圍繞接觸、切斷、包圍、偏轉、壓縮與環境傳播作近中距攻防；禁退化為無來源遠程光團對轟。
6. **生物／巨獸／機械**：以真實軀體結構交鋒，不套用人類劍術或輕功。

## 3. 三層專業內核與九環因果鏈

編排順序不可顛倒：

1. **電影級動作導演**：定衝突目的、空間主軸、路線節點、危險區、強度曲線、第一次逆轉、終局落點、每段鏡頭資訊任務。戰鬥是單一因果鏈：`搶空間 → 對真實線路反制 → 接觸與位移 → 新高度/破綻 → 追擊 → 攻守逆轉 → 終結與餘波`。
2. **武術指導**：校驗攻擊路線、重心、接觸與受力。每個關鍵攻防交換或優勢轉換須完整走完**九環因果鏈**（連擊內可共用結果，不強行每一下都炸場）：
   `起勢/重心 → 加速 → 明確攻擊線 → 接觸或險些命中 → 合理應對 → 形變/反震 → 沿力線位移 → 環境結果 → 下一動作觸發`
   格擋與落空保留動量並改變下一線；嚴禁「打完一招—雙方復位—再起一招」。
3. **角色行為設計師**：每個選擇符合目標、體型、風險偏好與累計受擊狀態。輕靈者切線變向借力；沉重者壓迫封路利用慣性；反擊必利用前招留下的重心、距離、視野或裝備破綻。

### 狀態繼承鐵律
- 每次切鏡只改變觀察角度，**下一鏡至少繼承 4 項**：位置、朝向、速度/方向、高度/支撐面、資產狀態、受擊/優勢狀態、環境餘波。
- 至少一次環境破壞必須改變後續路線、支撐、遮擋、危險區或優勢。

## 4. 五段狀態接力（15 秒標準結構）

| 區間 | 階段任務 | 必須寫清的內容 | 鏡頭任務 |
|---|---|---|---|
| **0–3s** | 即時開戰與首次完整攻防 | 無對峙開場（首接觸 ≤0.5s）；搶位方連出 ≥2–3 條不同攻擊線；首次接觸寫清接觸點、反震、受力方向與第一處破壞；錯身即追擊 | 衝入接觸點 |
| **3–6s** | 改變軸線與首次明確命中 | 繼承動量，借坡面／台階／殘牆／柱體改變高度或方向（無飛行能力者只能靠跳躍、攀附、墜落、拋飛或借力騰空）；命中後沿力線飛出、翻滾、滑退並合理恢復 | 揭示高度與位移 |
| **6–10s** | 技術交換與第一次逆轉 | 從滑退／翻滾／踉蹌中直接進入；設計「迫使偏移 → 逼近 → 針對載體拆解 → 利用重心漏洞反震／控臂／切角／翻摔」，將原優勢方震開或逼入危險區 | 看清技術與重心 |
| **10–13s** | 追殺封鎖與環境折返 | 占優方封鎖路線；被壓制方借移動中碎石、牆體、煙塵或結構折返，穿越封鎖時有可讀閃避與擦碰，從側／背／低位盲區改軸反擊 | 追蹤封鎖與折返 |
| **13–15s** | 三拍終結與明確結果 | 敗者在受創失衡中做最後合乎事實的反擊 → 勝者三拍（逼出可預判防禦 → 借已變重心換軸繞側 → 從真實方向命中）；寫清接觸點、受力位移、環境破壞、敗者落點與餘勢運動（衣料、塵霧、碎石、火花持續到最後一幀） | 看清終結路線與戰場結果 |

> **≤10 秒短時長四段**：依序走 `即時搶攻 → 接觸後變線 → 持續追擊與攻守轉換 → 仍在運動中的切出或指定結果`，不硬塞終局敗倒與站定收勢。

## 5. 雙語同步交付合約（中文導演母稿 → H3 Ref2VA 英文六段）

### 5.1 預設交付順序
除非使用者明確指定「只要中文」或「只要英文」，預設固定輸出**一對同步成稿**：

1. **中文導演母稿（供人快速審核打戲邏輯）**：
   - 15 秒用七段：`項目總述`、`0—3 秒`、`3—6 秒`、`6—10 秒`、`10—13 秒`、`13—15 秒`、`聲音與禁止項`（段內明確標出實際切鏡時間點）。
   - ≤10 秒用六段：`項目總述`、四個連續時間區間（含切鏡點）、`聲音與禁止項`。
   - 不出現 `<Subject N>`、`<Picture N>` 或英文 H3 欄位名；不保留方括號佔位符或 TODO。
2. **English H3 Ref2VA Prompt（單一可直接複製送入模型的 code block）**：
   - 嚴格按六欄位順序：`subject_definitions:`、`summary:`、`retention_analysis:`、`detailed_description:`、`overall_soundscape:`、`non_diegetic_music:`。
   - **不強制加 `BUNNY`**：僅在使用者明確指定特定 LoRA 觸發詞時才放首行；Pika H3 Flex / ComfyUI-Dials 路線一律不加額外 LoRA 觸發詞。
   - 負面約束全面轉寫為正面保持句（詳見 `references/output-format.md`，避免 `no/not/never/without/rather than`）。

### 5.2 母稿不可變與時間線 1:1 同步規則
- 英文稿**必須完整繼承**中文母稿的角色數量、外觀、武器、能力、開局空間、動作因果、切鏡數量、切鏡順序、切鏡秒數、聲音事件、勝負與最終餘波。
- 中英文**鏡頭數與切鏡時間必須嚴格一致**；英文不得自行拆分、合併或偷加新角色／武器／結果。
- 參考標籤設計：角色／巨獸定義為 `<Subject 1>`, `<Subject 2>`（標明來源 `<Picture N>` 並填滿 `ref-identity-lock.md` 9 類特徵），場景定義為 `<Subject 3>`（標明作為環境基礎而非鎖死構圖）；僅在圖片作為首尾幀構圖錨點時才單獨以 `<Picture N>` 參照。
- `detailed_description` 首句與 `[Shot 1]` 首句放一致的 **3–4 個畫風材質錨**（≤3 個形容詞防靜止）；`[Shot 1]` 不寫時間碼，後續鏡頭一律 `[Shot N] At MM:SS.mmm, ...` 嚴格遞增。
- 若啟用「無停頓連續模式」，英文稿嚴禁出現 `charge up`、`pause`、`hold`、`brake`、`settle`、`freeze`、`pose` 等靜止詞，每個 shot 結尾已進入下一動作。

## 6. 輸出前靜默檢核（失敗必回上游重寫）

1. 每個角色僅使用圖中可見或明確指定的武器與能力；無武器者全程徒手；資產無串線。
2. 每個主體動作嚴格符合已選載體，雙方依非對稱矩陣攻防。
3. 關鍵接觸均含應對、受力、位移、環境結果與下一觸發；切鏡繼承 ≥4 項狀態；無原地復位。
4. 角色臉部特寫必寫肌肉動作（見 `facial-performance.md`）；招式符合多樣性與三高度原則。
5. 15s 五段／≤10s 四段結構與無停頓開關無違規；最後 1–2 秒保持進行中動作（實拍時搭配安全邊界裁尾）。
6. 英文 Ref2VA 六段與中文母稿鏡頭數、時間碼、勝負結果 100% 同步，且通過 `python scripts/validate_prompt.py <檔> --duration <秒>` 0 FAIL。

## 7. 實戰紅線增補（v3.0 動作物理合理性與雙軌 Dial 硬規格）

1. **姿態—位移相容律（徹底根絕「跪姿貼地滑雪」與「腳不沾地溜冰步」）**：
   - **接地鎖死姿態禁配高速平移**：凡出現 `kneels / crouching low / hand pressing ground / horse stance / sitting` 等接地釘樁姿態，同鏡內**嚴禁**搭配水平衝刺或高速橫移運鏡（`sprints / charges across / tracks sideways fast`），且執行層必須掛載 **`--anchor t0:t1:-0.65`** 將淨等效運動壓在 `≤ 0.0`（抵銷 `h3_storm` 的 `+0.375` 運動洩漏），把動態交給劍陣展開、衣袂翻飛與碎石懸浮！
   - **主動進攻嚴禁寫 `slide / skid`**：全篇禁止濫用 `slides / skids / glides across ground`（`validate_prompt.py` 達 2 次直接判 FAIL）。每一次水平位移與變向必須寫出**離散步態三拍（Discrete Gait Cycle）**：`drives hard off right boot`（蹬離支點）→ `lunges / vaults across`（跨步騰躍）→ `plants left boot firmly on stone seam, sinking stance`（前腳踩實沉腰吃力）。
