# 多段打鬥：分鏡工程與接縫（N 段拼接）

> 單段寫得好 ≠ 整片接得起來。多段片的成敗在**段與段之間**：身份、空間、道具狀態、
> 動作相位、光色，任何一項跳掉，觀眾立刻出戲。
> 來源：h3-fight 多段一致規則（sourced）、h3-prompt-journal 自含式分段與 hand-off（sourced）、
> ayase long-form-planning 接點載體（sourced）、本 repo fl2va-chain 與 round2/round3 實測（measured）。

## 1. 分鏡先行：寫提示詞之前先交三份表

**沒有這三份表就不要開始寫段落提示詞。**

### 1.1 節拍表（每段一行組）

```text
S{n}｜{秒數}｜一句主題（這段只帶一個劇情節拍）
  Shot 1（區間）一拍：建立位置 → 攻擊 → 接觸/格擋 → 反應收勢
  Shot 2（區間）…
  接點載體：<動量/視線/道具接觸/聲音/姿態 之一>
  尾態 hand-off：<重心/支撐腳/軀幹朝向/衣物餘勢/頭方向/機位>
```

- 一段只帶一個劇情節拍（繳械、被逼退、破核），其餘全是打。長對話放文戲段。
- 升級曲線不平均分配：`建立→接觸→壓制→反擊→高光→危機（放慢一拍）→反攻→收尾對峙`。
- 收尾停在可交接的狀態，不要收在動作中間。

### 1.2 狀態帳本（哪些東西會壞、哪些全片不動）

| 物件 | 段 a | 段 b | 段 c | 誰在哪一鏡打壞 |
|---|---|---|---|---|
| 例：木柱 | 完整 | 完整 | 裂 | 雷蒼雷錘把霜寧撞上去（c 鏡 1） |

規則（h3-fight，sourced）：
1. **一直不動的東西**：場景定義寫 `stays … throughout this video`，大招寫明 away from 它。
2. **要打壞的東西**：在哪一鏡、被誰的哪一招打壞，寫進那一鏡。
3. **打壞之後的段只寫剩下的樣子**：`a short broken stump where the flagpole used to be`，
   不寫 `the tall flagpole … already cut`——後者升鏡頭時旗杆會長回來。
4. **打壞版場景圖不預畫**：等上一段出完，用完好版圖當底（管機位）＋上一段實際尾幀當參考
   （管壞成什麼樣）再生成。預畫的破壞常和 H3 實際打壞的樣子對不上，掛上會和首幀打架。
   **R3 measured（2026-11-19）**：t1-c 只靠文字寫「祭壇斷成兩半」＋完好場景參考圖→
   祭壇還是完整的（圖壓過文字）；手持兵器斷裂（round2 T4）純文字可成，因為兵器不在場景圖裡。
   **規則細分：場景固定物（祭壇／柱／牆）的破壞必須換打壞版場景圖；角色手持道具的破壞可用文字狀態。**
5. **人物外形變了**（袖燒損、甲裂）：下一段的人物定義寫變化後的樣子，否則衣服會穿回來。

### 1.3 接縫表（每個切點一行）

| 接點 | 載體 | 下段開場怎麼承接 | 拼接處理 |
|---|---|---|---|
| a→b | 動量 | b 鏡 1 寫「他已搶進半步」 | 硬切 |
| b→c | 聲音＋光 | c 開場即衝擊波 | 切在衝擊瞬間，必要時 0.3s 叠化 |

**五種連續載體**（ayase，sourced；每個切點至少留一種，下段開頭直接接住）：
1. **動量**：上段收勢的餘勢（人還在滑、拳還在收）
2. **視線**：看的還是同一方向／同一人
3. **道具接觸**：刀刃還壓在同一位置、手還抓著手腕
4. **聲音**：切点落在同一聲撞擊／共振的尾巴上
5. **姿態**：乾淨好接的靜止姿勢（單膝著地、背靠牆、錯身而過）

## 2. hand-off 寫法（段尾→段首）

- 段尾提示詞寫死交接狀態：**重心、支撐腳、軀幹朝向、袖/衣物餘勢、頭的方向、機位位置**。
- 下段開場**逐字承接**該狀態，點名到具體肢體與高度（「右手在腰高」），
  不寫抽象的「延續動量」（journal，sourced）。
- 每段都是獨立生成，模型沒有上一段的記憶：**必要的鎖與規則在每段重寫**
  （身份、站位、道具當前狀態、場景當前狀態），但外觀細節交給參考圖，文字只寫狀態。
- 段長自檢：累積和核對，上段結束＝下段開始，無重疊無空檔。

## 3. 切段點選擇（比寫法更重要）

1. **靠衝力的動作在同一段做完**（衝刺、攀爬、追壓）。在衝力中途切段，
   下一段首幀是靜止畫面，人會從靜止重新起步（h3-fight，sourced）。
2. **切段點選在上一段原本就切鏡的節拍 boundary**：一次交手結束的收勢、
   命中瞬間、落地瞬間。這些點本來就是硬切，接縫最便宜。
3. 想加強的瞬間（落地、重擊、破核）**獨立成約 1 秒一鏡**，配專門機位；
   擠在上一鏡末尾力度會被稀釋（h3-fight，sourced）。
4. 新人物從畫外進來：上段末幀沒有的角色，下段別讓他第 1 幀就站著（會憑空冒出）。
5. 上段停在特寫→下段第 1 鏡切全景時**重寫誰左誰右**，不會翻邊。

## 4. 接續方式決策表（本機 REMIX Pika 路线）

| 方式 | 什麼時候用 | 限制 | 證據 |
|---|---|---|---|
| **獨立生成＋拼接**（預設） | 不同機位、切鏡、換段 | 每段重寫鎖與 hand-off；接縫用 seam_check 驗 | round2/3 measured |
| `continue_from`（tail latent） | 同一鏡頭延長、不切鏡 | 同模式同畫幅；來源要有 tail；≤2 段，超過要寫硬切回中景，否則畫面逐段拉近 | remix guide measured（2026-11-05） |
| `pikaff768` 首幀模式（first_frame=job:<id>） | 構圖必須釘死上一段尾幀 | **不掛角色包**，身份靠幀本身；不支援接續；多段鏈身份會漂 | guide sourced，本輪未用 |
| FL2VA 首尾幀（Singularity） | 狀態 A→B 精確過渡 | 掛幀不套 RefMod；不能與 continue_from 併用 | guide sourced |

**多段打鬥預設走獨立生成**：打鬥段段有切鏡，continue_from 的「同一鏡頭」假設不成立；
首幀模式丟角色包，跨段身份風險大於接縫收益。

## 5. 接縫 QC（每段完成後、拼接前）

```bash
# 1. 死格檢查：接縫那一格畫面變化比率 <50% = 接不上
python scripts/seam_check.py prev.mp4 next.mp4
# 2. 運動曲線：尾端站樁就剪掉（H3 末 1–2 秒自動減速，多要 1.5 秒是安全邊界）
python scripts/measure_motion.py clip.mp4 --fps24
# 3. 身份：REMIX GET /jobs/{id}/identity，fail 重抽
# 4. 人工看接縫前后各 0.5 秒的抽幀：左右有沒有翻邊、光色有沒有跳、道具狀態對不對
```

拼接規則：
- 硬切接縫跳的地方加 **0.25–0.3 秒叠化**（h3-fight，sourced）。
- 钉了首幀的段拼片時去掉第 1 幀。
- 每段尾端站樁剪掉再拼（round2 measured：seg2 末/中只有 43–44%）。
- 音訊：H3 原生同步音效逐段生成；拼接後 loudnorm −16 LUFS（REMIX /stitch 自帶）。

## 6. 常見接縫失敗

| 症狀 | 根因 | 修法 |
|---|---|---|
| 下段開場人物從靜止重新起步 | 切在衝力中途 | 切段點移到收勢/命中/落地 |
| 左右翻邊 | 上段特寫→下段全景沒重寫站位 | 下段鏡 1 重寫誰左誰右＋軸線 |
| 打壞的東西長回來 | 下段寫了「原本有…」 | 只寫剩下的樣子 |
| 衣服穿回來 | 下段人物定義沒寫變化後狀態 | 狀態帳本逐段復述 |
| 怪獸/場景尺寸跳動 | 沒有尺度參照 | 見 monster-scale.md |
| 接縫死格 | 兩段尾首狀態都靜 | 換載體（動量/聲音），或叠化 |

**R3 measured（2026-11-19）：持姿勢收尾的段必產死格接縫。**
T1/T3 四個接縫 seam_check 全 FAIL（比值 22–24%）——蓄力 hold 接 release hold、
follow-through hold 接天空寬景、錨槍 hold 接鑽蓄力，尾首都是靜止 pose。
T2 連續對轟段尾/中 93%（動作中收尾），三個接縫全 PASS（YAVG 差 10.79 正常）。
**規則：段尾要收在動作中（餘勢、滑步、轉身半路），不要收在 held pose；
做不到就 0.25–0.3s 叠化（xfade fade＋acrossfade tri），實測可修死格。**
大招蓄力段與收尾段本質是靜的，叠化是這類段的標配，不是補救。
