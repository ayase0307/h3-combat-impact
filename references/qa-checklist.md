# 驗收清單與故障排除

## A. 生成前自檢（逐項打勾）

**結構**
- [ ] `[Shot 1]` 沒有時間碼
- [ ] 後續鏡頭時間嚴格遞增，且都在時長內（例：7 秒片不能出現 `At 00:08.000`）
- [ ] 第一句有風格錨定（`3D CG, cinematic` / `live-action` 等）
- [ ] 三個欄位齊全，沒有多餘欄位（T2VA/FL2VA）

**運鏡**
- [ ] 每個鏡頭只有**一個**機位運動
- [ ] 每個運動都有「類型 + 幅度 + 速度」或明確省略
- [ ] 主體動作與鏡頭運動沒有同向疊加
- [ ] `shakes strongly` 只出現在 L3/L4

**打擊**
- [ ] 至少有一次完整的六拍（蓄→觸→停→洩→退→收）
- [ ] 命中拍寫了**幀數**（`for two frames`）
- [ ] 有 Hit Stop 句（`decelerates to a near-freeze`）
- [ ] 衝擊波有**方向**（`outward along the ground` 而非 `everywhere`）
- [ ] 有環境反應（燈火/瓦片/水/雨）
- [ ] 有延遲跟隨（`a beat late` / `follow-through`）

**設計（最常被跳過、也最致命）**
- [ ] 有**交換**：弱勢方至少打中一次
- [ ] 有**後果**：撞斷東西、摔下台階、面具裂、刀脫手
- [ ] 空間被壓小（窄道／台階／貼牆，不是空曠大廳）
- [ ] 開局 0.8 秒內有第一次接觸，沒有「站著對視」
- [ ] 每招**具名**（不是 `slashes`、`attacks`、`strikes`）
- [ ] 三招一組涵蓋三個不同高度（上／中／下）

**預算**
- [ ] 每 7 秒 ≤6 個鏡頭
- [ ] 全段只有一個 L4
- [ ] L4 之前有 0.5–1 秒的靜
- [ ] **時間碼總長 = 生成時長**（末鏡不超過總長 30%）
- [ ] 字數：4–8 秒 ≤520、9–15 秒 ≤700
- [ ] 重要約束不在最後一段

**可量測（生成後跑 `scripts/measure_motion.py`）**
- [ ] 開場 0.8s ≥ 中段的 50%
- [ ] 末 2s ÷ 中段 ≥ 60%
- [ ] 最長低潮 ≤ 0.8s
- [ ] 峰值格 ≥ 4
- [ ] 主體在最後 2 秒有位移或姿勢變化（不只看分數，要目視）

**力場與爆炸**（有爆炸／能量／熱浪時必查）
- [ ] 衝擊幀寫了幀數（`for two frames`），不是「一瞬間」
- [ ] 震屏寫了衰減與回穩時間（`decays ... within a third of a second`）
- [ ] 閃白、震屏、衝擊波三者寫在同一個子句或相鄰句，確保對齊
- [ ] 力場至少開了三個通道（光／空氣／物質／粒子），不是只有碎片
- [ ] 有「反向證據」：主角的衣襬或頭髮被推
- [ ] 持續性場（熱浪、瘴氣）用了進行式（`keeps rippling`），不是一次性爆炸
- [ ] 沒有用術語代替描述（`Field 力場擾動模擬` 這類詞已拆成具體物理句）

**約束**
- [ ] 所有「不要」已改寫成「保持」正面句
- [ ] 角色外觀關鍵特徵在每個出現的鏡頭都重述一次

## B. 生成後驗收（看這 8 點）

| # | 檢查 | 不合格的表現 |
|---|---|---|
| 1 | 命中是否可讀 | 看不出哪一幀打中 → 蓄力或停頓不足 |
| 2 | 是否有重量 | 被打的人像紙片飄走 → 缺 Hit Stop + 環境反應 |
| 3 | 方向是否一致 | 火花往四面八方 → 衝擊波沒寫方向 |
| 4 | 臉是否變形 | 命中後五官糊掉 → 該鏡頭缺「保持」句 |
| 5 | 兵器是否變形 | 劍變軟/融化 → 缺 `stays perfectly straight and rigid` |
| 6 | 布料是否活 | 衣襬像紙板 → 缺 `a beat late` / 氣壓描寫 |
| 7 | 剪輯是否清楚 | 兩個鏡頭黏在一起 → 鏡頭數過多或景別沒跳級 |
| 8 | 音畫是否同步 | 撞擊聲晚半拍 → `overall_soundscape` 沒寫撞擊音，或寫在錯誤順序 |
| 9 | 爆炸是否有空氣 | 像發光球 → 缺空氣通道（折射／熱浪／壓縮） |
| 10 | 爆炸是否有體感 | 只看到、沒被震到 → 缺震屏衰減或沒有對齊 |

## C. 常見故障與對應修法

| 症狀 | 根因 | 修法（改一句就好） |
|---|---|---|
| 動作像慢動作播放 | 整段都寫了 slow / 沒有速度對比 | 刪掉所有 `slow`，只留蓄力段；命中段加 `at fast speed` |
| 打擊無聲 | `overall_soundscape` 只寫環境音 | 加 `a deep bass impact followed by a sharp metallic crack` |
| 特效像貼圖 | 只寫顏色與發光 | 加「與誰互動」：`the flame is dragged into a spiral by the blade's motion` |
| 主角飛起來沒有原因 | 缺蓄力與地面反作用 | 加 `she drives off her rear leg, cracking the flagstone beneath her` |
| 一閃就結束，沒有餘韻 | 缺「洩」與「收」 | 加 `embers drift down through the lantern light` |
| 兩個角色長得一樣 | 沒有逐項外觀鎖定 | 為每人固定 4 項特徵並在每個鏡頭重述 |
| 鏡頭一直在轉 | 多鏡頭都給了運動 | 留一個 `static shot` 作為錨點 |
| 爆炸太大，主體不見了 | L4 佔比過長 | 縮短爆炸，改為 `the shockwave passes; she is still standing` |
| 生成到 10 秒後開始崩 | 單段塞太多事件 | 切段，用 FL2VA 接續 |
| 顏色忽冷忽熱 | 沒有色彩腳本 | 在 `[Shot 1]` 指定 `teal energy against amber lantern light`，後續不再改 |
| 爆炸旁邊的布和頭髮不動 | 物質通道缺失 | 加 `wind pressure flattens the silk against her body` |
| 爆炸邊緣很乾淨、像剪紙 | 空氣通道缺失 | 加 `the air tears into layered sheets that bend the background` |
| 熱浪看起來像靜止濾鏡 | 把持續性場寫成一次性 | 改成 `keeps rippling` + 強度起伏 |
| 爆炸後畫面立刻切走 | 沒有沉降 | 加 8–20 幀的餘燼與煙塵 |
| 能量光完全沒出現 | 弱事件用了 2 幀爆閃，被平滑插值抹掉 | 改成 `stays lit` 持續附著，或獨立成一個鏡頭 |
| 冷色能量變成白色 | 亮度比不過場景主光 | 改用 `the only cold light in the frame` 宣告唯一性 |
| 對手只擋不打 | 攻擊只寫了結果沒寫路徑 | 寫成「抬刀 → 下劈弧線 → 終點」三段 |
| 兩人全程貼身像跳舞 | 沒有寫交手後的距離變化 | 每次交手後加 `steps back two paces` |
| 該斷的東西沒斷 | 用否定式邏輯（「不是她，是紗」） | 正面寫三個狀態：劃過 → 斷口 → 飄落 |
| 該斷的東西整條被扯飛 | 只寫「切斷」沒寫「局部」 | 給位置 + 尺寸 + 保留條件：`at hip height`、`a hand-span`、`the rest stays on her headdress` |
| 眼神／姿態約束失效 | 寫在鏡頭最後一句，權重被後面的動作蓋過 | 移到鏡頭**第一句**，並綁具體動作（`head turned toward him`） |
| 雙武器只剩一把 | 只寫 `both blades` | 分別寫位置：`the right blade above his head, the left blade low across his body` |
| 收勢變成投降姿勢 | 沒指定身體狀態 | 明寫 `she settles into a low guard, weight on the back foot` |
| 姿態漂亮但沒有威脅感 | 模型的「優雅角色擺拍先驗」 | 不要加 `fierce` 這類形容詞；改成讓她一直在動，或讓對手壓過來 |
| 靜止鏡頭裡她低頭 | 凝視指令無效 | 用動作驅動視線：`her eyes drop to his blade, then snap back to his mask` |
| 整段「很優雅但很無聊」 | 缺交換、缺後果、空間太大、招式抽象 | 四項一起補，不要只補一項 |
| 動作只有「揮、擋、退」 | 用了抽象動詞 | 從 `move-library.md` 取具名招式 |
| 開場很沉悶 | 用對峙開場 | 0.8 秒內給第一次接觸 |
| 快切只落地一半 | 7.5 秒寫超過 6 刀 | 砍到 6 刀以內；時間碼往前寫 0.2 秒 |
| 尾端兩人對看 | 最後一鏡用了寬景＋reset | 改特寫或動作中段收尾 |
| 寬景出現多餘人影 | 動漫風遠景人形缺乏細節 | 加 `exactly two figures, no duplicates` |
| 角色道具突然變色 | 缺少特寫錨定 | 每 2–3 刀插一個角色特徵特寫（拳套／飾品／鞋） |
| 主角在中段消失 | 句子主語寫成對手 | 主語換成主角，但保留對手的標籤 |
| 特寫鏡頭兩秒不動 | 特寫沒有內部運動 | 加手指收緊、鞋底摩擦、鐵鍊晃動 |
| 兩個角色長一樣／服裝特徵互換 | 全部用 she／her，沒有互斥標籤 | 兩人各用固定標籤（黑髮 vs 粉髮），每句點名 |
| 主角打自己 | `her own chin` 這類懸空所有格 | 改成明確歸屬：`the block jolts the black-haired fighter's head back` |
| 刀很多但整體很平 | 剪點增加了、動作沒增加 | 動作寫進每一刀，不要靠加刀數 |
| 尾端人物站定不動 | ①時長比時間碼長 ②只寫「不要站著」 | 先對齊時長；再寫主體位移（`advances two steps`） |
| 運動分數達標但看起來還是靜 | 特效運動冒充主體運動 | 加主體位移或姿勢變化，不要加粒子 |
| 主角被特效擠成小點 | 沒寫人物佔比 | 加 `occupying 65–80% of the frame height` |
| 後段約束完全失效 | 提示詞太長，約束寫在最後 | 砍到 450 字內，把約束往前移 |
| **整片像「燈光故障」而不是衝擊** | 只寫爆白，或爆白幀數不對 | 改用漫畫格三段式：`2 幀黑白放射線格 → 1 幀黑 → 回彩色` |
| **最大衝擊那一鏡整個糊掉** | 最大的衝擊也給了大幅度運鏡 | 那一鏡鎖死相機（`holds a static shot`），讓特效推開背景 |
| **甩鏡看起來像鏡頭自己在亂動** | 甩鏡沒指定跟隨對象 | 加 `following the fighter`（甩鏡要跟主體甩） |
| **能量顏色飄移，跟角色對不上** | 只寫「A 用藍、B 用紫」 | 用眼瞳／寶石當錨點：`the cold fighter's irises glow ice-blue` |
| **夜戲的能量被背景吃掉** | 背景不是單一色相 | 把環境調成單色相，讓武器彩度成為唯一異物 |
| **劍看起來不夠大** | 只描述「劍很大」 | 用已知物比出來：倒木、樹幹、身高對比 |
| **刀光揮完就消失** | 只寫附著在武器上的光 | 加「離手不散」：`the light does not disperse; it stays as a hair-thin thread crossing the entire frame` |
| **參考片分析數字全部偏低 20%** | 參考片是 30fps，沒折回 24fps | 絕對值乘 1.25；跨片比前先統一幀率 |
| **逐幀分析炸出幾百個假切點** | ffmpeg 重抽成 CFR60 | 加 `-fps_mode passthrough` |

## D. 改版時的回歸檢查（每次迭代必做）

**症狀：修好一個問題，弄壞三個原本好的地方。**

實例：為了改善「出拳太單一」，把編排從 3 個動作擴到 9 個招式——結果同時丟掉了角色圖（改用 T2VA 遷就比例）、衝擊幀（只有第 1 鏡有）、震屏、極特寫。使用者評價：「人物完全沒照參考圖，特效、切鏡、聚焦、打擊感及快節奏蕩然無存。」

### 每次改版前，先勾這六項

- [ ] **角色來源沒變**（有參考圖就一定走 I2VA／Ref2VA，不要為比例改 T2VA）
- [ ] **每一擊都還有 2 幀爆閃**
- [ ] **還有至少一個極特寫插切**
- [ ] **還有震屏（帶衰減）**
- [ ] **剪點數沒失控**（7.5 秒 ≤6 刀）
- [ ] **角色標籤兩邊都在**（不是只有主角）

### 兩條鐵律

1. **比例不能凌駕身份。** 角色圖是 9:16 就拍 9:16。用 16:9 硬套會裁掉手腳或拉寬，改用 T2VA 則直接失去角色。身份優先。
2. **改動要疊加，不要替換。** 想加強編排，就在原有 sakuga 語言上「加」，不是把 sakuga 換成編排。

## D2. 迭代策略（一次只改一個變因）
1. **先修節奏**（鏡頭數、時間碼）——節奏錯，畫面再好也不能用。
2. **再修打擊**（六拍是否齊）。
3. **再修運鏡**（是否有單一機位、幅度是否合理）。
4. **最後修美術**（顏色、材質、粒子密度）。

每次重生成只改一項，並保留其餘文字不變，才能判斷是哪一句造成差異。

## E. 分段與接續檢查

- [ ] 每段 ≤15 秒（實務建議 ≤8 秒）
- [ ] 段與段之間有 0.3–0.5 秒的**重疊動作**，方便剪接時對齊
- [ ] 接續段的 `Picture 1` 確實是上一段的**最後一幀**（不是倒數第二幀）
- [ ] 接續段第一句重述了首幀的姿勢與光線
- [ ] 全片只有一組色彩腳本
