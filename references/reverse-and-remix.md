# 雙入口工作流：原創導演（模式 A）與逆向衍生抽卡（模式 B）

> 吸收自參考影片《Skill H3 打戲技能應用》與《MiniMax H3 樣片模式超燃打戲合集製作流程》，把「寫提示詞」升級為「多方案一採抽卡 → 擇優二採修復 → 三採超分」的完整 Agent 生產閉環。

---

## 1. 兩種入口模式

| 模式 | 觸發條件 | Agent 執行流程 |
|---|---|---|
| **模式 A · 原創導演** | 使用者提供角色圖／場景圖／一句需求，從零設計打戲 | ① 建事實帳本＋9 載體路由 → ② 先交「簡明劇情與五段／四段骨架」讓使用者確認（若已完全明確則直接往下）→ ③ 產出雙語同步稿（中文母稿＋H3 英文六段）→ ④ 匹配 `ComfyUI-Dials` 配方並送一採抽卡 |
| **模式 B · 影片逆向＋衍生** | 使用者提供一支參考打鬥影片，要求拆解復刻或做變體 | ① 用 `ffprobe` + `ffmpeg` 抽幀與量測（`measure_motion.py --fps24`），拆出鏡長分布、動作因果鏈、攻防轉換點、特效與運鏡節奏 → ② 檢查缺漏資產（缺角色／巨獸／場景時，先用 `codex exec` 逐個補生乾淨 3D CG 圖）→ ③ 產出 **3 份並列方案**：**方案 1（高保真復刻版）**＋**方案 2（高張力反殺／變線衍生）**＋**方案 3（奇觀環境互動衍生）** → ④ 先跑方案 1（或三案並列）一採抽卡 |

## 2. 三段採樣工業化流水線（樣片模式 5.0 升級版）

高燃打戲**不是一次 768p 盲抽**，而是把算力花在「已經驗證過動作結構的好種子上」：

```text
[一採 Draft 抽卡]  480p / 640p（854×480 或 1088×640），Pika 6 步 + DialRack
   │  耗時：每支 15s 約 60–90 秒（5070 Ti）
   │  任務：同時驗 2–3 個提示詞方案或種子，只看「動作連不連貫、載體對不對、構圖夠不夠燃、衝擊點有沒有落準」
   ▼
[篩選與修詞]  跑 measure_motion.py --fps24 --symmetry + 目視接觸表
   │  淘汰：開場過靜、人物變形、武器增生、原地擺拍
   │  保留：動作張力與攻防線最優的 1 個方案與 seed
   ▼
[二採 Final / De-rope 精修]  768p（1344×768），Pika 6 步 + DialRack + De-rope（H3JerkOracle → H3TimeSmear → MAIDialHoldMap → H3V2VInit → H3ExactRecover）
   │  耗時：8s 約 3–4 分鐘，15s 約 6–8 分鐘
   │  任務：保留 Pass 1 優秀動態與原音訊，消除高速糊化、掉幀與果凍感，拉滿人物細節
   ▼
[三採 2× 超分＋裁尾定稿]  ReCaVSR 2× 超分（768p → 2688×1536）＋ 必要時裁去末尾 1.0–1.5s 自動減速段
      耗時：約 1–2 分鐘
      任務：輸出 2K 銳利成片並產出對照驗收指標
```

## 3. 缺資產自動補生規範（Codex CLI）

當模式 A 或模式 B 缺少角色／巨獸／場景參考圖時，嚴格遵守 `ref-identity-lock.md` §8.6：
1. **畫風鎖定**：採用「乾淨光滑的 3D 國漫 CG 設定圖（smooth clean PBR 3D donghua CG）」，**禁用厚塗油畫筆觸**（6 步 LCM 會糊成一團）。
2. **逐個執行**：呼叫 `codex exec --sandbox workspace-write` 一次生成一張，確認 PNG 存在與尺寸正常後再跑下一張（禁止並行搶資料夾）。
3. **圖數控制**：標準對決用 3 張（主角＋對手＋無人場景圖）；非必要不超過 4 張，避免 Ref2VA 注意力稀釋。
4. **構圖規範**：
   - 角色圖：1536×1024 四視圖（左 1/3 臉部 3/4 特寫＋右 2/3 正／側／背全身）或單人 3/4 戰鬥預備姿，純中灰底、無文字、無水印；武器型號與比例一次定死。
   - 場景圖：16:9（1536×864 或 1536×1024），**畫面絕對無人**，單一明確主光源，前／中／遠三層深度清晰。
