# 劇本式輸出契約（combat 版）

> 用途：開場 0.5 秒就要接觸、禁止項多、要衝擊幀、單鏡長動作、後端是 hosted／有改寫器。
> 只用來寫**一段**（≤8 秒）；多段請改用自含式長段（見 `references/formats.md`）。
> 這份格式不吃 `[Shot N] At` 的硬切精度；要準切點就回官方骨架。

## 1. 欄位順序（固定，不可調換）

| # | 欄位 | 職責 | 寫壞會怎樣 |
|---|---|---|---|
| 1 | `[參考鎖]` | 每張圖「只取什麼／不要什麼」 | 模型把參考圖的站姿、灰底、排版一起畫進來 |
| 2 | `[畫風]` | 一個畫風錨 ＋ 一句「不是什麼」 | 錨太多變靜止圖；沒有「不是」會變插畫 |
| 3 | `[可重複部件]` | 會在時間軸反覆出現的長描述（電、煙、雨、血霧、火花、水花） | 每鏡重寫＝稀釋；只寫一次＝中段消失 |
| 4 | `[站位表]` | 空間錨點 ＋ 左右 ＋ 軸線 | 換邊、越軸、兩人重疊 |
| 5 | `[本段]` | 時長、鏡數、逐秒時間軸 | 主動作排隊＝模型只做第一件 |
| 6 | `[聲音]` | 環境音、撞擊音、有沒有人說話 | 模型自己配樂／加對白 |
| 7 | `[連續性]` | 首態 → 尾態（一句） | 下一段接不上 |
| 8 | `[硬約束]` | 禁止項全部集中在最後 | 散在句子裡會被動作句淹掉 |

## 2. 每欄的硬規則

### `[參考鎖]`
- 一張圖一行：`<Picture N>=名稱：只取 A、B、C；不要 D、E。`
- 人物：只取身份／臉／髮／服裝／配件；**站姿、背景、排版一律寫「不用」**。
- 場景：只取佈局、材質、光源方向；**不要**把參考圖裡的人畫進來。
- 有武器的圖要寫清楚「武器只有一把、在右手、不憑空生成第二把」。

### `[畫風]`
- 格式：`正常畫面：<一個錨>，<兩個材質形容>。不是 <A>，不是 <B>。`
- 錨最多 3 個（例：`超精細 3DCG、電影感、濕夜寫實光照`）。
- 一定要有「不是什麼」（例：`不是二次元平塗，不是遊戲過場`）。

### `[可重複部件]`
- 只放「每次出現都要長一樣」的東西：電弧、煙、雨、血霧、衝擊火花、水花。
- 每個部件一段，寫**形狀→顏色→行為→何時消失**。
- 時間軸只寫「何時出現」，不重寫外觀。

### `[站位表]`
- 先寫三個空間錨點（左／右／後），再寫人物（誰在左、面向哪），最後寫軸線（機位在哪一側）。
- 兩人以上一定要寫；一人可以省略。

### `[本段]`
- 第一行：`N 秒，M 個鏡頭，機位<固定/推進/橫移>`。
- 逐秒格式：`0.0-2.3秒｜<誰><做什麼><結果>。`（全形｜，時間用半形小數）
- **一段時間軸只能有一件主動作**；次要動作寫成「同時」的子句。
- 每個時間段結尾要有「狀態變化」（他退了、刀斷了、燈滅了），不能只是「兩人對峙」。

### `[聲音]`
- 三段：環境底噪／撞擊與動作音／人聲（有沒有人說話、嘴唇是否閉著）。
- 沒有配樂就寫「沒有配樂」；不要留空。

### `[連續性]`
- 一行：`首態：<畫面> → 尾態：<畫面>`。給下一段看的，不是給模型看的。

### `[硬約束]`
- 全部用「無…／不要…／只有…」的短句，一行一條。
- 必寫：無字幕、無文字、無水印、畫面不分格；人數；武器數量。

## 3. 8 秒骨架（直接抄，換內容）

```text
[參考鎖]
<Picture 1>=女劍客：只取她的臉、黑色高馬尾、左眉細疤、深青無袖立領戰袍、黑腰封、炭灰束口褲、黑布靴、小臂白布纏帶；參考圖的站姿、劍、灰底、排版都不用。
<Picture 2>=蒙面力士：只取鐵半面具、刀疤下巴、光頭、赭色無袖上衣、黑皮帶、灰褲、鐵頭靴、一根鐵棍；站姿與灰底不用。
<Picture 3>=雨夜廢寺庭院：只取濕石板地、左邊斷矮石牆、右邊倒地石燈籠、後方木門樓、簷下暖黃燈籠、冷藍夜雨；庭院裡沒有其他人。

[畫風]
正常畫面：超精細 3DCG、電影感、濕夜寫實光照。不是二次元平塗，不是遊戲過場動畫。

[可重複部件]
火花＝撞擊點爆出的白熱火花，中心亮白、外緣金橙，只出現在兵器接觸那一瞬，濺開約一個手掌大，隨即熄滅；不持續發光。

[站位表]
空間錨點：斷石牆＝左；倒地石燈籠＝右；木門樓＝正後方。
角色站位：女劍客在畫面左、面向右；力士在畫面右、面向左。
軸線：機位一直在兩人連線前方，不越軸。

[本段]
8 秒，三個鏡頭，機位貼近。
0.0-2.5秒｜中景。兩人半步對峙；開場半秒內女劍客後腳蹬地、搶進半步，反手撩出一記低斬砍向力士前膝；力士把棍身橫壓下來硬接，撞擊點爆出火花。
2.5-5.5秒｜硬切貼身近景。鐵棍壓住刀身，兩雙手握到指節發白；力士把重心壓進去，女劍客手腕一翻把鐵棍甩到外側，力士被帶得退滿一步，後腳在積水裡打滑。
5.5-8.0秒｜切回中景。她保持前進，畫面結束時正在邁步、刀已抬到腰際；他重心不穩、棍尾點地。

[聲音]
大雨打在石板與木簷上；接觸那一下一聲尖銳的 steel-on-iron；鐵棍被甩開時一聲金屬刮擦；靴底滑過積水。沒有人說話，兩人嘴唇閉著；沒有配樂。

[連續性] 首態：兩人在積水裡相隔半步、兵器未接觸 → 尾態：力士退了一步、重心不穩，女劍客正在前進、刀在腰際。
[硬約束] 無字幕、文字、水印、標誌；畫面不分格、不拼圖；畫面裡只有這兩個人；女劍客只有一把刀、左手空著。
```

## 4. H3 在本機的脾氣（screenplay 作者實測 ＋ 本 repo 量測）

| 寫法 | H3 的反應 | 對策 |
|---|---|---|
| 步頻（「每一步 1.3 秒」） | 不聽 | 只寫步數與方向（「這 4 秒走 3 步」） |
| 絕對秒數（0.0–2.3） | 常晚 0.2–0.8 秒 | 重要切點用官方骨架，或預留 buffer |
| 場景全靠文字 | 會自己編 | 場景一定要給參考圖；文字只補「不要什麼」 |
| 「暫停」「定格」 | 變成慢動作 | 用「動作變慢但不停」或後製凍格 |
| 「鏡頭快速搖」 | 變成整片晃 | 寫「小幅、慢速」，或鎖死相機 |
| 衝擊幀寫 2 幀 | 給 21–23 幀 | 寫 4–6 張卡片 × 0.3–0.45 秒，剪輯時剪快 |
| 多人沒有站位表 | 換邊、越軸 | `[站位表]` 必寫 |
| 否定句散在各處 | 前段有效、後段失效 | 集中到 `[硬約束]` |

## 5. 交付前十問

1. 每張參考圖都寫了「只取什麼／不要什麼」嗎？
2. 畫風錨 ≤3 個、且有「不是什麼」嗎？
3. 反覆出現的特效有抽到 `[可重複部件]` 嗎？
4. 有站位表與軸線嗎（兩人以上必填）？
5. 每個時間段只有一件主動作嗎？
6. 每個時間段結尾有狀態變化嗎？
7. 有寫「有沒有人說話、嘴唇是否閉著」嗎？
8. `[連續性]` 有首態與尾態嗎？
9. `[硬約束]` 有集中、且包含字幕／分格／人數／武器數嗎？
10. 這段最怕丟的那一拍，是否真的寫在時間軸上（不是寫在期望裡）？
