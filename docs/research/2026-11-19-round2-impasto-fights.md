# 第二輪：日系寫實厚塗 × 三題長打鬥 × 大招

日期 2026-11-19。後端：本機 ComfyUI、Pika H3 Flex LoRA、1344×768、6 步。
圖片資產：codex 內建 imagegen。每題 3 段 × 8 秒，種子固定 1001，**每個設定只跑 1 次（n=1）**。

### 「密而不水」判準

每一句話都要能在畫面上指出一個區域、一個動作或一個數量。
- **留**：位置與畫面左右、每拍的順序與秒數、接觸點與力的方向、物件的形狀顏色、起點與終點狀態。
- **刪**：堆疊的品質詞（cinematic、epic、超精細）、重複的畫風宣告、沒有可見線索的氣氛形容、不影響構圖的焦段數字。

### 有衝突、需要實測才能定的外部說法

- 否定句：fal 說有效；本機 skill 測試 3/3 失敗。→ 一律用「場景安排」，不依賴「不要」。
- 長度：外部說 80–120 字；本機實測 1,900–2,800 字元可用。→ 本輪三題都在 2.5–2.8k 字元，結構完整。

### 學到的事

1. **風格守得住**：三題都保持可見筆觸的厚塗；T2（現代場景）偏寫實，T1／T3（和風）最像畫。
   風格段落放在 `detailed_description` 一次即可，沒有重複宣告。
2. **移動可以靠場景安排做出來**：爬販賣機、蹬鳥居、跳欄杆、摔下凍河都出現了，
   前提是「一鏡一個位移」。
3. **大招的視覺特效不難，因果事件才難**：蓄力、環境反應、墨爆、衝擊波每題都出；
   「兵器被打斷／義肢碎裂／面具碎裂」三題全部沒有清楚出現。這是跨題、跨上輪的穩定失敗模式。
4. **每段尾端會停**：seg2 的末/中只有 43–44%，剪尾即可（成片已剪）。
5. **A/B（n=1，只當傾向）**：本後端上官方骨架的節拍較準時；劇本式較不站樁但節拍落後。
   與 h3-screenplay-prompt 作者在 Pika 480 的「開場較活」不同，**不可推廣**。
6. **validator 校準問題**：劇本式提示詞被判 2 FAIL，原因是檢查器只認官方格式；
   這是檢查器的問題，不是提示詞的問題。

### 斷刀變體（T1 seg3_break，observed，n=1）

把大招改成「一刀斬斷柄」，並把斷裂單獨放在一個鏡頭（鏡頭 2），寫成**可看見的結果狀態**：
半截刀點朝下插進冰面立著、他手裡只剩短斷柄、切口一條白光。結果：**第一次出現兵器斷成兩截**，
墨爆與衝擊波、掀飛仍在。

副作用（同樣是觀察）：斷刀那個鏡頭的背景變回參考圖的灰底，劍士不在畫面內；
「忽略參考圖灰底」的指示在這一鏡沒有守住。下一步要試：在該鏡頭裡明寫場景（橋、凍河、月）與她的位置。

→ 暫定規則（待多種子驗證）：大招的因果事件不要塞進「三連擊」，單獨一個鏡頭、一個斬擊、
寫成結束後的狀態；並在該鏡頭重述場景與兩人位置。

## 3.5 第三輪：換參考圖風格（T4 狐妖對退魔劍士）

起因：使用者反映成片比平常的 768p 糊。排查：輸出編碼正常（1344×768、約 7 Mbps、crf 18）；
工作流與 remix-studio 的 `pika768` 預設相同（lcm 6 步、Sol-Attn），所以不是設定差。
改用「左臉部特寫＋右正／側／背、灰底平光」的乾淨光滑 CG 設定圖，戰鬥化服裝，
場景用高飽和千本鳥居。同種子 1001，`scripts/measure_sharpness.py`（拉普拉斯方差，越高越銳）。

| 片 | 清晰度中位數 | p10 |
|---|---|---|
| T1 厚塗 seg1 | 46.7 | 39.7 |
| T3 厚塗 seg1 | 59.9 | 38.7 |
| T2 seg1（現代、偏寫實） | 68.1 | 47.5 |
| T4 seg1 穩定運鏡 (S) | 133.4 | 101.2 |
| T4 seg1 手持甩鏡 (H) | 115.7 | 67.3 |
| T4 seg2 (S) | 128.8 | 39.4 |
| T4 seg3 大招 (S) | 208.5 | 48.8 |

結論（observed＋measured，內容與光線不同，**方向性證據、非受控實驗**）：
1. **厚塗參考圖是糊的主因**：6 步 LCM 還原不了高頻筆觸，會塗成一團；乾淨光滑的設定圖清晰度約高 2 倍。
   厚塗風格要保留的話，需要另外驗證（例如只在場景用、角色用乾淨圖，或加超分）。
2. **手持甩鏡寫法再損失約 15%**（p10 差更多）；穩定運鏡＋只在撞擊拍震一次，動作量沒掉（末/中 89%）。
3. **超分（ReCaVSR／Tessera）沒驗證**：remix-studio 服務沒開；T4 不放大已清楚很多，所以它不是唯一原因。
4. **大招斷兵器成功（T4 seg3）**：一刀斬斷單獨一鏡、寫成結束狀態，並在該鏡**重述場景與兩人位置**，
   這次沒有灰底外洩。副作用：斬後那一鏡約 2.5 秒定格站姿，斬擊本身只在甩動幀出現。
5. **石階追逐**：她往下朝鏡頭跑而非往上，方向與分鏡不一致；方向要在提示詞裡寫「朝畫面深處／朝鏡頭」。
6. **並行生圖陷阱**：三個 codex 生圖並行會搶同一個產出資料夾（檔名被改成 exec-*.png，且可能誤存到別的目錄）。逐個跑。

成片：`docs/research/runs/t4/fight-21s.mp4`。
