## 這一輪學到的事（measured）

1. **密度上限**：本地 6 步 LCM 路徑，一鏡 ≈ 2.6–2.9 秒才能完成「一個交換」。
   4 鏡 / 5.17 秒會退化成一鏡一個姿勢（0–1 次接觸）；3 鏡 / 8 秒可給 1–3 次接觸。詳見
   `references/choreography.md` §9。
2. **換 sampler 不是解**：Pika＋euler 8 步、768p turbo＋euler 8 步都試過，接觸次數沒有變多；
   問題在內容密度，不在取樣器。
3. **要更快，靠剪輯**：每段尾端都會自己站定（0.5–1.5 秒），剪掉之後成片才緊。
4. **左右換邊**：第 5 段模型把她放到右側，破壞軸線；成片用水平翻轉修回（`hflip`）。
   這是後製補救，不是生成時控制的。
5. **大招最難的是「因果」**：雨環、三連、墨爆、掀飛都生得出來，但「棍被打斷」這一個
   可數事件沒有穩定出現——要在提示詞裡把它寫成一個獨立鏡頭，或後製補。
